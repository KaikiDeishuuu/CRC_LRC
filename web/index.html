CRC / Checksum API Tool

This tool provides various checksum calculations via a web API.

📖 API 文档

1️⃣ 字符串/十六进制输入 (GET)

GET /api/v1/checksum?input=YOUR_STRING_OR_HEX

输入格式：

  • 文本字符串： 直接输入文本，如 HelloGo
  • 十六进制： 以 0x 开头，如 0x48656C6C6F476F
  • 十六进制（带空格）： 如 0x48 65 6C 6C 6F 47 6F

示例请求：

  • /api/v1/checksum?input=HelloGo - 文本输入
  • /api/v1/checksum?input=0x48656C6C6F476F - 十六进制输入（无空格）

响应示例：

{
  "input": "HelloGo",
  "inputBytesHex": "48656c6c6f476f",
  "results": {
    "CRC16_CCITT": {
      "decimal": 49195,
      "hex": "0xC08B"
    },
    "CRC16_MODBUS": {
      "decimal": 57975,
      "hex": "0x77E2"
    },
    "CRC32_IEEE": {
      "decimal": 3762696614,
      "hex": "0xDFF7B826"
    },
    "SUM8": {
      "decimal": 72,
      "hex": "0x48"
    }
  }
}

2️⃣ 文件上传 (POST)

POST /api/v1/file-checksum

上传要求：

  • Content-Type： multipart/form-data
  • 字段名： file
  • 文件格式： 支持任意二进制文件（.bin, .hex, .txt, .dat 等）
  • 文件大小限制： 最大 10 MB（可在配置文件中调整）

支持的文件类型示例：

  • 二进制文件：.bin, .dat
  • 文本文件：.txt, .log
  • 十六进制文件：.hex, .ihex
  • 其他：任意格式的文件都可以计算校验和

响应示例：

{
  "input": "File: example.bin (Size: 1024 bytes)",
  "inputBytesHex": "48656c6c6f...",
  "results": { /* 与字符串输入相同的结果格式 */ }
}

3️⃣ 支持的校验算法

算法 说明 应用场景
CRC16_MODBUS 多项式 0xA001，初始值 0xFFFF Modbus 协议、工业通信
CRC16_CCITT 多项式 0x1021，初始值 0xFFFF X.25 协议、蓝牙通信
CRC32_IEEE 标准 CRC32（IEEE 802.3） 以太网、ZIP、PNG、MPEG-2
SUM8 8位累加和校验 简单校验、NMEA 协议
